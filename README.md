# Calendar App (React + Django DRF + MySQL)

A modern, production-oriented full-stack calendar application with a focus on security, usability, and clean design.

## 🚀 Key Features

- **Dual-Auth Login**: Login seamlessly with either your **Username** or **Email address**.
- **Smart Calendar Navigation**:
  - **Tile Previews**: High-level view of your notes directly on the calendar grid.
  - **Go to Date**: Instantly jump to any specific date with a dedicated search tool.
  - **Local-Time Calendar**: Accurate date selection and display that respects your local timezone.
- **Enhanced Security**:
  - **Simple One-Click Reset**: A streamlined forgot-password flow that resets to `username@123456789` and autofills the login form.
  - **Security Alerts**: Automatic warnings when logged in with a simple, autogenerated password.
  - **Admin Safeguards**: Protective logic preventing administrators from accidentally inactivating their own accounts.
- **Admin Panel**: Complete user management interface for administrators to monitor and manage access.
- **Responsive Design**: Premium aesthetics with modern typography and a mobile-friendly layout.

## 🛠️ Tech Stack

- **Frontend**: React (Vite), React Router, Axios, React Icons.
- **Backend**: Django 5.0 + Django REST Framework.
- **Database**: MySQL / TiDB Cloud Serverless.
- **Deployment**: Prepared for **Vercel** (Frontend & Backend).

## 💻 Local Setup

### Backend (Django)

1. **Virtual Environment**:
   ```powershell
   cd backend
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
2. **Environment Configuration**:
   Create a `.env` file in the `backend/` directory using the provided `.env.example`.
3. **Database Setup**:
   ```powershell
   python manage.py migrate
   python manage.py createsuperuser
   python manage.py runserver
   ```

### Frontend (React)

1. **Install Dependencies**:
   ```powershell
   cd frontend
   npm install
   ```
2. **Environment Configuration**:
   Create a `.env` file in the `frontend/` directory and set `VITE_API_BASE_URL=http://localhost:8000/api`.
3. **Start Development Server**:
   ```powershell
   npm run dev
   ```

## ☁️ Deployment Guide

### Option A: Render (Backend) + Vercel (Frontend) [Recommended]

#### 1. Backend (Render)
- Create a **Web Service** on [Render](https://render.com/).
- Root Directory: `backend`
- Environment: `Python 3`
- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn calendar_backend.wsgi:application`
- Add environment variables (same as the table below).

#### 2. Frontend (Vercel)
- Create a project on [Vercel](https://vercel.com/).
- Root Directory: `frontend`
- Framework Preset: `Vite`
- Add `VITE_API_BASE_URL` pointing to your Render URL.

## 🛡️ Security Implementation

- **CSRF Protection**: Automated pre-fetching and header injection via Axios interceptors.
- **Session Security**: Secure, HTTP-only cookies with configurable SameSite policies.
- **Input Validation**: Human-readable error parsing for backend validation failures.
- **Admin Permissions**: Restricted access to user management and system settings.
